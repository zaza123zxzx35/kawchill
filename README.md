# Teacher Exam Radar

เว็บส่วนตัวบน Windows สำหรับเทียบเขตสอบครูผู้ช่วย เอกภาษาอังกฤษ สังกัด สพฐ. ใช้ข้อมูลที่ดึงได้จริงจากหน้าสถิติสาธารณะ แล้วให้จำลองสถานการณ์บนเครื่องโดยไม่เขียนทับข้อมูลต้นทาง

## เปิดใช้งาน

ดับเบิลคลิก `start.bat`

สคริปต์จะสร้างสภาพแวดล้อม Python ติดตั้งไลบรารี แล้วเปิดเบราว์เซอร์ที่ `http://localhost:8501`

เมื่อเปิดแอป ระบบจะตรวจไฟล์ PDF ใน `data/source_pdfs/` อัตโนมัติด้วย SHA-256 เก็บไฟล์ที่ไม่เคยนำเข้า ข้อความแยกรายหน้า และหลักฐานดิบลงใน SQLite เดิมโดยไม่เขียนทับตารางข้อมูลสอบ ระบบจะไม่เดาตัวเลขจากตาราง PDF ที่อ่านซับซ้อน แต่จะแสดงรายการ `รอตรวจสอบ` ในแท็บ **PDF หลักฐาน**

PDF ที่ติดตั้งมากับโปรเจกต์มี 5 ไฟล์ ได้แก่คู่มือเลือกเขต ไฟล์อัตราเปิดสอบ/เกษียณ และบัญชีคงเหลือปี 2566–2568 หากมีไฟล์ version ใหม่ ให้วางเพิ่มใน `data/source_pdfs/` แล้วกด **ตรวจ PDF ใหม่อีกครั้ง** ในแท็บดังกล่าว ไฟล์เดิมจะถูกข้ามตาม hash และไฟล์เก่าจะไม่ถูกลบ

ถ้าต้องการดึงข้อมูลจากบรรทัดคำสั่ง:

```bat
.venv\Scripts\python -m src.refresh
```

แอปจะดึงใหม่เองเมื่อเปิดใช้งาน หากข้อมูลล่าสุดที่สำเร็จเก่ากว่ารอบที่ตั้งไว้ ค่าเริ่มต้นคือ 6 ชั่วโมง เปลี่ยนรอบได้ที่แถบด้านข้าง ช่วงที่อนุญาตคือ 1 ถึง 168 ชั่วโมง เพื่อไม่ให้ยิงเว็บต้นทางถี่เกินไป ขณะปิดแอปจะไม่มีการดึงข้อมูล

## ข้อมูลที่ใช้

- ตารางเขตมาจาก [สถิติเอกภาษาอังกฤษบน kruphuchuay.com](https://www.kruphuchuay.com/report.php?r=4/5) เฉพาะหน้าที่ไม่ได้ระบุว่าเป็นกรณีพิเศษ จึงจัดเป็นการคัดเลือกทั่วไป
- ลิงก์ประถม มัธยม และการศึกษาพิเศษเป็นมุมมองย่อยของหน้าเดียวกัน แอปใช้หน้ารวมแล้วแยกสังกัดจากชื่อเขต
- ภาพรวมทั้งประเทศบนหน้าเดียวกันถูกเก็บแยกจากแถวรายเขต เพราะเขตที่เปิดปีก่อนแต่ไม่ได้เปิดในปีปัจจุบันไม่ได้อยู่ในตารางรายเขต
- อัตรากำลังรายเขตมาจากหน้ารายละเอียดของแหล่งเดียวกัน และถูกใช้เป็นบริบทเท่านั้น
- [HRMS สพฐ.](https://hrms.obec.go.th/info/majorStandard/major10Years/) ให้ความต้องการทดแทนครูภาษาอังกฤษระดับประเทศ 10 ปี ไม่มีตัวกรองรายเขตในหน้าที่เปิดสาธารณะ และไม่ถูกนำไปแทนจำนวนตำแหน่งสอบ
- หน้าแรกของ obec.go.th, personnel.obec.go.th และ otepc.go.th ถูกตรวจว่าเข้าถึงได้หรือไม่ หากไม่มีตารางสอบเอกภาษาอังกฤษ แอปจะไม่สร้างตัวเลขจากหน้าเหล่านั้น

นำเข้า CSV หรือ XLSX ได้จากแท็บแหล่งข้อมูลเมื่อต้องการเพิ่มประกาศที่ดึงอัตโนมัติไม่ได้ ไฟล์ต้นแบบอยู่ที่ `data/templates/recruitment_import.csv` ข้อมูลนำเข้าถูกแยกแหล่งจากข้อมูลที่ดึงจากเว็บ

PDF เป็นหลักฐานประกอบแยกจากข้อมูลเว็บเดิม อัตราเกษียณในเอกสารเป็นยอดรวมทุกวิชา จึงไม่ถูกใช้แทนตำแหน่งเอกภาษาอังกฤษ และแถวเอกอังกฤษจากบัญชีคงเหลือจะถูกเก็บเป็นหลักฐานเพื่อตรวจชื่อเขต/ตัวเลขก่อนนำเข้าข้อมูลหลัก

## การอ่านผล

ช่องที่ไม่มีตัวเลขจะขึ้นว่า **ข้อมูลไม่เพียงพอ** ปีที่ต้นทางระบุว่าไม่เปิดสอบจะขึ้นว่า **ไม่เปิดสอบ** ไม่ถูกบันทึกเป็นศูนย์

คะแนนรวมต้องมีอย่างน้อยอัตราผู้สมัครต่อตำแหน่ง หรือประวัติเรียกบรรจุ นอกจากจำนวนตำแหน่งที่เปิดรับ สูตรและน้ำหนักแสดงในแท็บอันดับ คะแนนเป็นเครื่องมือเทียบภายในรายการที่กรองอยู่ ไม่ใช่การพยากรณ์ผลสอบ

แท็บจำลองสถานการณ์ทั้ง 4 แบบคำนวณทันทีจากข้อมูลในเครื่อง และติดป้ายว่าเป็นประมาณการเชิงสถานการณ์

## ข้อจำกัด

- ปี 2569 บนหน้ารายวิชายังไม่ใช่ยอดสุดท้ายทั้งประเทศ หากหน้าเดียวกันยังระบุว่ามีเขตรอประกาศ เขตที่ไม่อยู่ในตารางเอกภาษาอังกฤษจะถูกแสดงว่าไม่มีข้อมูลหรือรอประกาศตามรายชื่อที่พบ ไม่ได้ถูกสรุปว่าไม่เปิดสอบ
- ประกาศ PDF ของเขตจะถูกเปิดเมื่อพบลิงก์จากหน้าเว็บเขต หากถอดอักษรไทยไม่ได้ ระบบจะเก็บ URL และสถานะไว้ให้เปิดตรวจเอง โดยไม่สร้างจำนวนผู้สมัครหรือจำนวนเรียกบรรจุ
- จำนวนผู้สมัครจะว่างจนกว่าหน้าต้นทางจะเผยแพร่
- ประวัติเรียกบรรจุรายเขตในตารางปัจจุบันเป็นของเขตที่เปิดในปีล่าสุดของหน้านั้น หลายเขตมีประวัติเพียงปีเดียว
- เว็บต้นทางเป็นข้อมูลรวบรวม อาจคลาดเคลื่อนจากประกาศของเขต ควรเปิดลิงก์เว็บเขตหรือประกาศทางการก่อนตัดสินใจ
- แอปไม่มีตัวเลขตัวอย่างที่ปลอมเป็นข้อมูลจริง หากยังดึงไม่ได้ ตารางจะว่างพร้อมสถานะดึงข้อมูลไม่สำเร็จ
